# Review a data path

Draw source → permitted execution context → raw → validated → serving.
For each step record the owner, stable key, retry boundary, credential reference,
quality rule, retention and operating cost. Mark where private connectivity is
needed and where personal data leaves its source. Explain each tool choice.

Review three failures: source unavailable, process lost after commit, and
out-of-order updates. Identify what can be replayed and what requires approval.
State the evidence for the proposal and the assumptions still needing a test.
